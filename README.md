## 🖼️ How to Replace Images

### **Important: Use Your Actual Project Images**

The website is currently using placeholder images. To showcase your real work:

### 1. Homepage Hero Background (`assets/images/hero.jpg`)
- **Recommended size**: 1920x1080 pixels
- **Subject**: A stunning interior design project (kitchen, living room, or elegant wardrobe)
- **Format**: JPG (optimized for web)

### 2. About Section Image (`assets/images/about.jpg`)
- **Recommended size**: 800x600 pixels
- **Subject**: A beautiful completed interior or your work process
- **Format**: JPG

### 3. Gallery Images (`gallery1.jpg` through `gallery6.jpg`)
- **Recommended size**: 800x600 pixels minimum
- **Subject**: Your 6 best completed projects
- **Format**: JPG
- **Tips**: 
  - Use high-quality, well-lit photos
  - Show different angles and services (kitchens, wardrobes, TV units, etc.)
  - Compress images for faster loading

### 4. Project Video (`assets/videos/noko-project.mp4`)
- **Recommended duration**: 30 seconds to 2 minutes
- **Format**: MP4 (H.264 codec)
- **Resolution**: 1080p or 720p
- **Subject**: Walkthrough of a completed project or installation process
- **Tips**:
  - Keep file size under 50MB for faster loading
  - Use video compression tools if needed
  - Ensure good lighting and steady footage

## 🚀 Deployment

### Option 1: GitHub Pages (Free & Easy)

1. Create a GitHub account at https://github.com
2. Create a new repository called `noko-interiors`
3. Upload all files to the repository
4. Go to **Settings** → **Pages**
5. Select **main** branch as source
6. Your website will be live at: `https://yourusername.github.io/noko-interiors`

### Option 2: Netlify (Free)

1. Create account at https://netlify.com
2. Drag and drop the entire project folder
3. Your site goes live instantly with a custom URL
4. You can connect a custom domain

### Option 3: Traditional Web Hosting

1. Purchase hosting from any provider
2. Upload all files via FTP or cPanel File Manager
3. Ensure `index.html` is in the root directory

## 🔧 Customization Guide

### Change Colors

Edit `css/style.css` at the top (CSS variables):

```css
:root {
    --color-black: #111111;      /* Change this */
    --color-gold: #C9A45C;       /* Change this */
    --color-white: #FFFFFF;      /* Change this */
    --color-light-grey: #F5F5F5; /* Change this */
}
```

### Add More Services

Copy a service card in `index.html` and modify:

```html
<div class="service-card animate-on-scroll">
    <div class="service-image">
        <img src="your-image.jpg" alt="Service Name">
    </div>
    <div class="service-content">
        <h3 class="service-title">Your Service</h3>
        <p class="service-description">Description here</p>
        <a href="https://wa.me/27727874863?text=Your%20message" 
           class="btn-gold" target="_blank">
           Enquire on WhatsApp
        </a>
    </div>
</div>
```

### Change Fonts

In `index.html` head section, replace the Google Fonts link:

```html
<link href="https://fonts.googleapis.com/css2?family=YourFont&display=swap" rel="stylesheet">
```

Then update in `css/style.css`:

```css
--font-primary: 'YourFont', sans-serif;
```

## 🆘 Troubleshooting

### Images Not Showing
- Check that image files are in the correct folder
- Verify file names match exactly (case-sensitive)
- Ensure images are in JPG or PNG format

### WhatsApp Links Not Working
- Verify phone number format: `27727874863` (no spaces or +)
- Test the link in a browser first
- Ensure WhatsApp is installed on mobile devices

### Mobile Menu Not Working
- Check that `js/script.js` is loaded
- Clear browser cache and reload
- Test in different browsers

### Video Not Playing
- Ensure video is in MP4 format
- Check file size (keep under 50MB)
- Verify the video path is correct
