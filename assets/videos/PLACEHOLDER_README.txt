NOKO INTERIORS - VIDEO PLACEHOLDER
==========================================

IMPORTANT: Add your actual project video here!

REQUIRED VIDEO:
===============

Filename: noko-project.mp4

VIDEO SPECIFICATIONS:
=====================

Format: MP4 (H.264 codec)
Resolution: 1080p (1920x1080) or 720p (1280x720)
Duration: 30 seconds to 2 minutes recommended
File Size: Under 50MB (compress if larger)
Aspect Ratio: 16:9 (landscape)

CONTENT IDEAS:
==============

✓ Walkthrough of a completed interior project
✓ Time-lapse of installation process
✓ Before and after transformation
✓ Close-up shots of quality finishes
✓ Multiple projects in one video (montage)
✓ Smooth panning shots of your best work

VIDEO TIPS:
===========

✓ Use good lighting (natural light is best)
✓ Keep camera steady (use tripod if possible)
✓ Film in landscape mode (horizontal)
✓ Show multiple angles of the same project
✓ Include variety of services (kitchen, wardrobe, TV units)
✓ Keep transitions smooth
✓ Add background music (optional, but professional)
✓ No copyrighted music (use royalty-free tracks)

HOW TO ADD YOUR VIDEO:
======================

1. Record or select a high-quality video of your work
2. Edit the video to 30 seconds - 2 minutes
3. Export as MP4 format (H.264 codec)
4. Compress if file is over 50MB:
   - Use: https://www.videosmaller.com
   - Or: HandBrake (free desktop software)
5. Rename to: noko-project.mp4
6. Copy the file to this folder (assets/videos/)
7. Refresh your website to see the video

VIDEO COMPRESSION TOOLS:
========================

Online:
- https://www.videosmaller.com (easy, free)
- https://www.freeconvert.com/video-compressor

Desktop Software:
- HandBrake (free, Windows/Mac)
- VLC Media Player (free, has compression features)
