IMAGE TIPS:
===========

✓ Use high-quality photos (clear, well-lit, properly focused)
✓ Show completed projects, not work in progress
✓ Include variety: kitchens, wardrobes, TV units, bedrooms, etc.
✓ Use landscape orientation (horizontal)
✓ Compress images for web (use tinypng.com)
✓ Keep file sizes under 500KB each for fast loading
✓ Use JPG format for photographs

HOW TO ADD IMAGES:
==================

1. Take or select 8 high-quality photos of completed projects
2. Rename them exactly as shown above (case-sensitive)
3. Compress them using https://tinypng.com
4. Copy all images to this folder (assets/images/)
5. Refresh your website to see the changes

NOTE: The website currently uses temporary Unsplash images as placeholders. 
These are served directly from Unsplash URLs in the HTML file and will work 
for testing, but you MUST replace them with your actual project photos 
before launching the website publicly.
